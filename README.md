## 这是什么

robocup搬运车比赛用四轮全向搬运机器人的下位机。一局比赛它要自己完成：

**出发 → 分点导航 → 收物料 / 奖杯 → 找圆对准 → 放料 → 回家**

代码分四层：`app`流程→ `algorithm`控制→ `device`定位接口→ `hardware`驱动。
**上层只认接口，换传感器只改 device 层那一行。**


`Core/Src/main.c` —— 外设初始化

`Core/Src/app_freertos.c` —— 七个任务

`app/worker_task.c` —— 比赛流程，**最重要**

`app/NavigationMecanum.c` —— 分点导航

`algorithm/angle_ctrl.c` —— 航向环

`CLAUDE.md` —— 设计约束与修改日志




### 给下一届的话

下一届可能地图大改，不过底盘控制方面依然可以复用，ops9的精度已经覆盖本科阶段绝大多数的比赛

针对这次国赛经历，建议大家提前准备好必要的措施以避免比赛时漏油，尤其是检查排线的连接，一定

要加固好比如打好热熔胶，可以安排一个队友提前检查来分担队长压力，备赛的时候优先追求精度然后

才是追求速度，关于学习方面的准备建议大家可以了解一下智能车的全向行驶组，学习一下他们的速度

规划策略（下面会附上开源的链接），关于底盘芯片的选择，我写这个md文档的时候g491的价格已经涨飞起了，不过我当时买的时

候价格还是正常的不过后面起飞了，要是到你们这时候价格还是没降下来，建议换回f4的系列，关于视

觉方面，其实上nx确实有点大材小用了（启动太慢了代价比较高），而maixcam pro是一个非常优秀的

视觉模块，完全可以胜任。最后祝你们能够在下一届robocup中大放光彩
