## 这是什么

robocup搬运车比赛用四轮全向搬运机器人的下位机。一局比赛它要自己完成：

**出发 → 分点导航 → 收物料 / 奖杯 → 找圆对准 → 放料 → 回家**

代码分四层：`app`流程→ `algorithm`控制→ `device`定位接口→ `hardware`驱动。
**上层只认接口，换传感器只改 device 层那一行。**


`Core/Src/main.c` —— 外设初始化

`Core/Src/app_freertos.c` —— 七个任务

`app/worker_task.c` —— 比赛流程，**最重要**

`app/NavigationMecanum.c` —— 分点导航

`algorithm/angle_ctrl.c` —— 航向环

`CLAUDE.md` —— 设计约束与修改日志
